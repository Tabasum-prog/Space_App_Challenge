# Pitch Script Outline

1. **Hook**: A billion objects and nobody can look at them all; we built a tool anyone can use to catch the ones that move.
2. **Live demo**: Open a story, press Blink, show the change, show the difference image.
3. **Depth**: Detective mode: candidate, cross-match, spectrum with a molecular feature, the statistics panel.
4. **Physics**: The isotope shift, the nuclear burning slider, and the Planet X calculator ending with the honest result.
5. **Credibility**: Known-object recovery and the efficiency curve.
6. **Impact and close**: Classroom use, citizen science, and what comes next.

## Q&A Prep
- **Did you find Planet X?** No. The calculator shows why a single SPHEREx exposure is unlikely to. The tool finds real movers and shows how to evaluate any candidate rigorously.
- **How do you avoid false positives?** Matched bands, flags, particle-hit tests, a trials-factor threshold, and cross-matches. We measured the false-positive rate.
- **Why do wavelengths matter?** SPHEREx's filters tie wavelength to detector position, so a naive blink compares different colors.
- **Is the physics real or decoration?** Each module is computed from real equations on real data, and P1 and P2 directly improve detection results.
- **Can the public use it?** Show Explorer mode with no setup, then show it on a phone.
