# Limitations

1. **Shallow Depth**: A real Planet X is very unlikely to be detected in single SPHEREx exposures due to shallow depth. The calculator explicitly shows this.
2. **Band-Matching Caveats**: Matching requires grouping exposures where the wavelength is within a small tolerance for the given pixel. This reduces the number of usable exposures and requires precise spectral WCS mapping.
3. **Simulated Data**: The current application uses purely synthetic demo data for all components except where clearly noted, as the real SPHEREx datasets were unavailable.
